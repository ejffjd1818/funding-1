# 오마이컴퍼니(OhMyCompany) 펀딩페이지 시안 프레임 가이드

오마이컴퍼니 리워드 펀딩 상세페이지([실제 페이지 링크](https://www.ohmycompany.com/reward/1803663166))를 1:1로 정밀 복제한 **제품 펀딩페이지 시안 와이어프레임(Prototype)**입니다.

---

## 🎨 원본 페이지와 똑같이 맞춘 디테일 요소

1. **상단 배너 및 공식 로고**
   - 오마이컴퍼니 고유의 블루(`#0091ff`) 배경과 노란색 강조 텍스트, 우측 `✕` 닫기 버튼
   - `OHMYCOMPANY` 공식 인라인 SVG 로고 (새싹 심볼 포함)
   - 공식 메뉴 (`후원하기` 그린 액티브, `투자하기`, `오픈예정`, `가이드`, `검색`, `로그인`, `펀딩 신청하기`)
2. **히어로 섹션 (상단 요약)**
   - 좌측: 4:3 비율의 대표 이미지 프레임 + 하단 캐러셀 인디케이터 도트 (활성 그린 바 & 비활성 도트)
   - 우측: 타이틀, `모인 금액` (30px), 달성률 `16%` (그린), 프로그레스 바(4px), `4명이 후원했어요`
   - 메타 리스트: 목표 금액, 펀딩 기간(27일 핑크 배지), 결제 시점, 펀딩 방식(ⓘ 툴팁)
   - 액션 버튼: 하트 찜하기(1), `후원하기` 그린 메인 버튼, 공유하기(0)
3. **상단 고정(Sticky) 탭 & 확실한 탭 전환**
   - `프로젝트 소개`: AI 요약 박스, 본문 이미지 슬롯 4종, 인용구(Quote), 제품 특장점(Point 1~4), 후원금 사용계획, 진행자 소개, 일정 안내
   - `커뮤니티`: 서브탭(`최근 소식`, `Q&A`, `프로젝트 후기`) 클릭 전환 완벽 지원
   - `후원자`: 오마이컴퍼니 실제 후원자 4인의 닉네임, 후원 시간, 응원 메시지, 금액 배지 카드 목록
4. **우측 고정(Sticky) 사이드바**
   - 창작자(주식회사 한결) 프로필 카드 (팔로워 0 / 응원 4 / 후기 0, `+ 팔로우`, `문의하기`, `더보기 ⌵`)
   - 리워드 선택 카드 3종 (50,000원+ 대좌, 40,000원+ 대, 30,000원+ 중) 세로형 옵션 리스트까지 동일 적용
5. **하단 푸터**
   - 공지사항, Google Play / App Store 버튼, 브랜드 로고, SNS 원형 아이콘, 사업자 정보 및 법적 고지

## 📸 사진과 텍스트를 나중에 추가하는 2가지 방법

### 방법 1. 웹 브라우저 화면에서 마우스 클릭으로 바로 추가 (실시간 테스트용)
코드를 열지 않고도 웹 브라우저에서 바로 내 사진을 넣어 시각적 배치를 테스트할 수 있습니다.
1. `index.html`을 웹 브라우저에서 엽니다.
2. 대표 이미지 박스나 본문의 빈 이미지 프레임을 **마우스로 직접 클릭**합니다.
3. 파일 탐색기 창이 뜨면 내 컴퓨터에 있는 사진 파일을 선택합니다.
4. 프레임 안에 사진이 즉시 채워지며, 우측 상단 `✕ 사진 제거` 버튼으로 언제든지 초기화할 수 있습니다.

---

### 방법 2. `index.html` 코드에서 영구적으로 사진 및 텍스트 수정하기
`index.html` 파일 내부에 찾기 쉽도록 `<!-- [사진 추가 방법] -->`, `<!-- [텍스트 수정] -->` 주석을 달아두었습니다.

#### 1) 사진 넣기
이미지 파일(예: `my_product.jpg`)을 프로젝트 폴더 안에 넣은 후, 원하는 이미지 프레임 태그 안에 `<img>` 태그를 삽입합니다.

- **대표 이미지 교체 시 ([index.html:90행 근처](file:///c:/Users/iwant/OneDrive/Desktop/2026/2학기/융창종/펀딩페이지/index.html#L90))**:
```html
<div class="media-frame-box" id="mainHeroImageSlot">
  <img src="my_thumbnail.jpg" class="uploaded-preview-img" alt="대표 사진">
</div>
```

- **본문 상세 이미지 교체 시 ([index.html:200행 근처](file:///c:/Users/iwant/OneDrive/Desktop/2026/2학기/융창종/펀딩페이지/index.html#L200))**:
```html

  <img src="my_detail_01.jpg" style="width: 100%; border-radius: 12px;" alt="상세컷">
</div>
```

#### 2) 텍스트 수정하기
- **프로젝트 제목 ([index.html:115행](file:///c:/Users/iwant/OneDrive/Desktop/2026/2학기/융창종/펀딩페이지/index.html#L115))**:

- **AI 요약 내용 ([index.html:190행](file:///c:/Users/iwant/OneDrive/Desktop/2026/2학기/융창종/펀딩페이지/index.html#L190))**:
